# homecart

Personal Rails app for automating grocery shopping. 

Starting vor v1 with ingestion of paper, PDF, and Drive receipts, building toward normalisation, spending analytics, price comparison, and more ?

Single-user, self-hosted.


## Stack (planned)

Rails 8, Ruby 3.x, Postgres 16, Solid Queue, Active Storage (disk), Tesseract + `pdftotext`, Hotwire.
